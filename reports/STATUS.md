## 핵심 관찰 (판정 아님, 사람 검토 입력)
- **응답 성립 10/10**. 오류·무응답·응답 중단 0건, 되물음 0건. FAIL 1건은 순수 소요시간 초과.
- **속도**: B 가 TC-02 제외 전 문항에서 12~27초 빠름 (PASS 기준 평균 A 61.3s / B 50.9s). 이미지 생성이 포함된 TC-02 는 양쪽 모두 최장(A 244.5s, B 97.2s).
- **토큰**: A 출력 토큰이 B 의 2~5배 (A 3.2k~18.8k / B 1.6k~3.7k). 입력 토큰은 문항별 편차가 커 모델 간 일관된 우열 없음. 10건 전부 화면 `Tokens > input/output` 표시값과 대조 확인.
- **출처 인용**: A 0/5 링크(실명·글 제목 언급은 TC-03·05) / B 2/5 링크(TC-04·05).
- **시각화 형태**: 양쪽 모두 TC-02 이미지 생성, TC-05 차트 렌더, 나머지는 표·카드·단계형. "시각화해줘" 요청에 텍스트만 응답한 문항 없음.
- **글자 깨짐**: B TC-05 마크다운 굵게 기호 날것 노출 1건(경미). 모지바케·대체문자 없음.
- **인프라**: A 세션 fork 가 `progress.jsonl` ts 를 UTC 로 기록 → 마무리 시 +9h 보정. result.md 에 계정 이메일이 적혀 있어 마스킹(과거 RUN-20260907-1622-dev 의 03 result.md 에도 잔존 — 별도 정리 필요).
