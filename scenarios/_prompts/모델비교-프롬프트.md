# 모델 비교 프롬프트 — Claude Sonnet 5 vs GPT 5.6 Terra

> **프롬프트는 이 파일 한 곳에만 적는다.** 채워지면 Claude 가 `scenarios/01-모델비교-A-Sonnet5.md` 와
> `scenarios/02-모델비교-B-GPT56Terra.md` 의 TC 로 **동일 원문**을 반영한다 (두 시나리오에 직접 쓰지 않는다 — 원문 불일치 방지).
>
> 작성 규칙
> - 1 프롬프트 = 1 블록(P01, P02 …). 필요한 만큼 블록을 추가·삭제한다.
> - **원문 그대로** 적는다 (오타·구어체·줄바꿈 포함). 비교 테스트이므로 다듬지 않는다.
> - 여러 줄 프롬프트는 ``` 펜스 안에 그대로 넣는다.
> - `관찰 포인트`·`비고` 는 선택. 비워 두면 Claude 가 시나리오 반영 시 채운다.
> - 이 폴더(`_prompts/`)는 `/qa-run` 카탈로그 스캔 대상(`scenarios/*.md`)이 아니므로 대시보드에 시나리오로 잡히지 않는다.
