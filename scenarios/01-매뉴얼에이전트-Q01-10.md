# 시나리오: 매뉴얼 에이전트 비교 — Q01~Q10 (Claude Sonnet 5)

## 메타 정보
- **ID**: SCN-01
- **우선순위**: P0
- **목적**: 하이웍스 사용 문의 30문항 중 **1~10번**을 AI채팅에 던져, **답변 내용**과 **응답 속도(체감 대기)** 를 실측·캡처한다. 같은 문항을 **dev(매뉴얼 에이전트 O)** 와 **prd(매뉴얼 에이전트 X)** 양쪽에서 실행해 A/B 비교 원천 데이터를 만든다. 판정보다 **증거 수집**이 목적인 비교 시나리오다.
- **지정 모델**: **Claude Sonnet 5** (Q01~10 구간 고정 — 대표님 지정)
- **비교 축**:
  - **에이전트 O** = `dev` 환경 (매뉴얼 에이전트 탑재)
  - **에이전트 X** = `prd` 환경 (매뉴얼 에이전트 없음)
  - 두 환경에서 **동일 문항·동일 모델**로 실행해야 비교가 성립한다.
- **사전 조건**:
  - **테스트 계정: `environments/{env}.md` 의 "일반 사용자1"** 로 로그인 (Q01~10 전용 계정 — 구간마다 계정을 바꾼다)
  - **TC 1건 = 새 대화 1개.** 좌측 **새 대화** 를 눌러 빈 컨텍스트를 만든 뒤 질문을 전송한다. 앞 문항의 대화를 이어서 쓰지 않는다.
  - 새 대화 진입 후 하단 **모델 선택기에서 `Claude Sonnet 5` 지정**. 지정 모델이 목록에 없으면 그 TC 는 `SKIP` + note 에 "모델 미제공" 기록.
  - 화면에 **매뉴얼/에이전트 관련 토글·선택 항목이 노출되면 활성 상태로 두고** note 에 그 명칭을 기록한다. 없으면 기본 상태 그대로 진행.
  - 코드 인터프리터 등 다른 부가 기능은 **건드리지 않는다** (기본 상태 유지 — 이번 시나리오와 무관).
- **검증 규칙**:
  - **직접 조작·검색 금지.** 오직 채팅창에 질문만 전송하고 AI 응답을 관찰한다.
  - **판정 기준은 "응답 성립" 여부만** — 답변 품질·정확도는 사람이 비교할 몫이므로 FAIL 사유로 삼지 않는다.
    - `PASS`: 질문에 대한 답변이 정상 생성되고 스트리밍이 완료됨
    - `FAIL`: 오류 메시지 · 무응답 · 응답 중단 · TC 타임아웃(90초) 초과 · 답변이 비어 있음
    - `SKIP`: 지정 모델 미제공 등 실행 자체가 불가
  - **각 TC 필수 산출물 3종**:
    1. `wait_ms` — 전송 직전 `t_send` → 응답 완료 `t_done` 실측 (**속도 비교의 원천 데이터. 추정값 금지.**)
    2. **답변 전문 스크린샷** — 답변이 1화면을 넘으면 `03b-after`·`03c-after` … 로 **다장 캡처**하여 전문이 빠짐없이 남게 한다
    3. `note` — 답변 요지 2~3문장 + **근거 문서·링크 인용 여부**(매뉴얼 출처를 제시했는지) + 되물음 여부
  - `in_tokens`/`out_tokens` 가 화면에 표시되면 기록, 없으면 `null`.
  - **멀티턴 금지** — 1문항 = 1턴. AI 가 되물어도 후속 답변을 하지 않고, "되물음으로 종료" 를 note 에 기록한 뒤 다음 TC 로 넘어간다. (되물음 자체가 비교 관찰 대상)
  - 스크린샷 슬러그는 **`agent-cmp-{env}`** (예: `agent-cmp-dev-tc01-03-after.png`). 파일명 규칙 나머지는 `/qa-run` SKILL.md 단일 출처.
  - 한 TC 가 실패해도 **끝까지 진행** (조기 abort 금지). TC 간 의존 없음 → `BLOCKED` 는 발생하지 않는다.
- **타임아웃 (이 시나리오 한정 상향)**: TC 1건 **90초**, 시나리오 전체 **20분**. CLAUDE.md 기본값(60초/5분)을 문항 수·매뉴얼 검색 지연을 감안해 덮어쓴다.

## 사용자 흐름

실사용자가 하이웍스 사용 중 막힌 지점을 AI채팅에 그대로 물어보는 상황을 재현한다. 문항마다 맥락 없이 처음부터 묻는 것이 핵심이라 **매 문항 새 대화**로 시작한다.

1. **새 대화 진입** — 빈 컨텍스트 확인
2. **모델 지정** — `Claude Sonnet 5`
3. **질문 전송** — `t_send` 기록 직후 전송
4. **응답 완료 대기** — 스트리밍 종료 시점에 `t_done` 기록
5. **답변 전문 캡처** — 길면 다장, 토큰 표시 있으면 함께 기록
6. `progress.jsonl` 즉시 append → 다음 문항은 **다시 새 대화**

## 공통 조작 순서 (전 TC 동일)

1. 좌측 **새 대화** 클릭 → 빈 컨텍스트 확인
2. 하단 모델 선택기에서 **Claude Sonnet 5** 선택
3. 채팅창에 **질문 원문 그대로** 입력 → `02-prompt` 캡처
4. `t_send = browser_evaluate(() => Date.now())` → **곧바로** 전송
5. 응답 스트리밍 종료 확인 → 즉시 `t_done` 기록
6. 답변 전문 캡처 (`03-after`, 넘치면 `03b`·`03c` …)
7. `progress.jsonl` 1줄 append

> 아래 각 TC 는 **질문 원문**과 **관찰 포인트**만 다르다. 조작 순서는 위와 동일.

## 테스트 케이스

### TC-01: 전자결재 메뉴 미노출 문의
- **질문**: `전자결재 메뉴가 안보이네?`
- **관찰 포인트**: 원인 진단형 답변인지(권한·서비스 미사용·관리자 설정) · 확인 경로를 구체적으로 제시하는지 · 매뉴얼 출처 인용 여부
- **비고**: 컨플루언스에 **기존 수기 비교본이 있는 문항**(3행 중 1건) — 재현성 대조 가능

### TC-02: 조직도 멤버 등록 방법
- **질문**: `조직도에 멤버 등록하는법 알려줘`
- **관찰 포인트**: 관리자 페이지 경로를 단계로 제시하는지 · 조직도 vs 사용자 추가를 구분하는지 · 매뉴얼 출처 인용 여부
- **비고**: 컨플루언스 **기존 수기 비교본 보유 문항**

### TC-03: 퇴사자 사용자 제거
- **질문**: `사용자를 제거하고 싶어요 퇴사해서요`
- **관찰 포인트**: 삭제 vs 사용중지(퇴사 처리) 구분 안내 여부 · 데이터·메일 승계 언급 여부 · 관리자 경로 제시
- **비고**: 컨플루언스 **기존 수기 비교본 보유 문항**

### TC-04: 전자결재 양식 생성 방법
- **질문**: `전자결재 양식 어떻게 만들어?`
- **관찰 포인트**: 관리자 > 전자결재 > 양식 관리 경로 제시 · 양식 편집기 사용법 단계화 · 권한 조건 언급

### TC-05: 새창 열기 차단 설정
- **질문**: `하이웍스 새창 열기 안되게 하는 방법 찾아줘`
- **관찰 포인트**: 실제 설정 항목을 특정하는지 · 브라우저 팝업 설정과 혼동하지 않는지 · 기능 부재 시 솔직히 없다고 답하는지

### TC-06: 로그인 계정 자동 저장 기능 유무
- **질문**: `하이웍스 로그인 화면에서 계정 자동 저장 기능은 없는거니?`
- **관찰 포인트**: 기능 존재 여부를 단정하는지 · 없으면 대안 제시 · **없는 기능을 있다고 지어내는지(환각)** 여부가 핵심

### TC-07: 일정 월간보기 섬네일 표시 항목 제어
- **질문**: `일정 월간보기에 섬네일에 표시되는 내용중 일정의 제목만 노출되게 하는 방법이 있나요?`
- **관찰 포인트**: 세부 설정 항목까지 도달하는지 · 지원되지 않으면 그렇게 답하는지 · **난이도 높은 세부 문항**이라 에이전트 유무 차이가 드러날 지점

### TC-08: 결재선 외 열람부서 고정 설정
- **질문**: `전자결재 양식 관련해서, 결재선 외에 열람부서를 고정으로 설정할 순 없을까?`
- **관찰 포인트**: 양식별 열람부서 고정 지원 여부 정확히 답하는지 · 대안(결재선 템플릿 등) 제시 · **세부 정책 문항**

### TC-09: 제미나이 3.1 Pro 사용량 정보 확인
- **질문**: `하이웍스 AI 채팅에서 제공하는 제미나이 3.1 pro 의 사용량에 대한 정보를 확인해줘.`
- **관찰 포인트**: 사용량(토큰·횟수 제한 등) 정보를 제시하는지 · **"제미나이 3.1 pro" 가 실제 제공 모델인지 정직하게 확인/교정하는지**(없는 모델을 전제로 답하면 환각 후보) · 사용량 확인 경로(메뉴) 안내 여부 · **제품 지식 문항**
- **변경 이력**: 2026-09-08 컨플 질문지 v30 반영 — 구 문항 `지피티 제미나이 클로드 유료인데 하이웍스에서 사용 하는건 뭐야?` (회차 1~3 결과는 구 문항 기준)

### TC-10: 수신자의 결재 단계 확인 가능 여부
- **질문**: `하이웍스 전자결재에서 수신자는 문서의 결재 단계가 어디인지 알 수 없어?`
- **관찰 포인트**: 수신자 권한 범위를 정확히 답하는지 · 진행 상태 조회 경로 제시 · 부정형 질문을 오해하지 않는지
